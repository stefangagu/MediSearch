# Features (Current)

This describes what MediSearch does today, from a user's perspective.

## Doctor Search & Discovery

- **Free-text search** — find doctors by name, specialty, clinic name, city, or address, all from a single search box.
- **Specialty filters** — narrow results down to one or more medical specialties, using the full list of medical specialties officially recognized in Romania (over 50 specialties, from Cardiologie to Medicină de familie to Chirurgie pediatrică).
- **Rating filters** — quickly show only well-rated doctors, with "4+ Foarte bun" (4 and above) and "3+ Bun" (3 and above) filters.
- **Clear filters** — reset search and filters back to the full list with one action.
- **Results count** — always visible, so users know how many doctors match their current search and filters.
- **Two browsing views** — a card grid for visual browsing, or a compact table view for scanning many results at once. On mobile, the grid view is used for a better fit on small screens.

## Doctor Profiles

Each doctor has a dedicated profile page showing:

- **Specialty** — clearly tagged on the profile.
- **Overall rating** — an average score (out of 5) plus the number of reviews behind it, or a clear "no reviews yet" state if there isn't enough data yet.
- **Practice locations** — every hospital or private clinic the doctor works at, including:
  - Clinic/hospital name
  - City
  - Full address
  - An embedded map for each location, so patients can immediately see where it is
  - Support for doctors who practice at **multiple locations** (e.g., a private clinic and a hospital in different cities)
- **Patient reviews** — individual reviews with a star rating, date, and short comment from the patient, sorted with the most recent first.

## Experience & Accessibility

- **Romanian-language interface** — built for the Romanian market from the ground up.
- **Light & dark mode** — automatically matches the user's system preference, with a manual toggle and the choice remembered for future visits.
- **Mobile-friendly** — on smaller screens, search filters collapse into a drawer to keep the layout clean, and the doctor list switches to the card view automatically.

## Current Data Note

The doctor directory currently runs on a curated sample dataset, used to validate the search experience, filtering, and profile layout. This is being replaced with a real, growing database of Romanian doctors as described in the [Roadmap](roadmap.md).
