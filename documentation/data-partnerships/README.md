# Data Partnerships & Official Data Outreach

This folder tracks outreach to official institutions that hold authoritative data on doctors in Romania — the kind of sources referenced in the ["Data Accuracy & Verification"](../product/roadmap.md) roadmap item.

Each file covers one institution/contact: background research, relationship status, and message drafts.

## Active

- **[CMR — Colegiul Medicilor din România](cmr.md)** — owner of the Registrul Unic al Medicilor (official doctor registry). Outreach in progress to the CMR president.
